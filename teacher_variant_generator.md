# Конструктор вариантов для преподавателя

Публичный репозиторий не должен раскрывать ответ конкретного варианта. Этот файл задаёт механизм генерации; фактический вариант выдаётся студентам отдельно.

## 1. Выберите скрытую первопричину

### A. Data pipeline

- сменились единицы измерения;
- изменился тип столбца;
- новая категория кодируется неверно;
- вырос missingness;
- сменился источник;
- изменился порядок preprocessing.

### B. Data drift

- новый сегмент;
- сезонность;
- смена канала/географии;
- изменение состава объектов.

### C. Concept drift

- изменилась зависимость target от признаков;
- изменились внешние правила;
- пользователи адаптировались к системе.

### D. Model/policy issue

- изменён threshold;
- другая версия preprocessing;
- изменена конфигурация модели;
- модель стабильна, но изменилась стоимость ошибок.

### E. Не модель

- upstream выдаёт неверные значения;
- downstream неверно интерпретирует прогноз;
- отчёт построен на другой выборке;
- target приходит с задержкой;
- жалобы относятся к редкому сценарию.

## 2. Добавьте отвлекающее свидетельство

Например: «обновили сервер», «появился новый релиз библиотеки», «пользователь написал, что раньше было лучше», «accuracy снизилась на 1%».

Цель — проверить confirmation bias.

## 3. Добавьте сильное доказательство

Оно должно быть обнаружимо правильной проверкой: масштаб ×1000, ошибки в новом сегменте, возврат threshold восстанавливает результат, downstream меняет знак и т. п.

## 4. Выберите осложнение

- target недоступен;
- бюджет сокращён;
- retraining невозможен до понедельника;
- признак запрещён;
- изменилась стоимость FN/FP;
- новый приоритетный сегмент;
- rollback недоступен;
- бизнес требует решение немедленно.

## 5. Минимальный пакет варианта

`case.md`, `reference.csv`, `current.csv`, `metrics.csv` (если target есть), `changes.log`, `messages.txt`, `complication.md`.

## 6. Проверка качества варианта

Вариант хорош, если:

- есть минимум 3 разумные гипотезы;
- первопричину нельзя узнать из одного сообщения;
- существует проверка, отличающая основную гипотезу;
- знания не выходят за рамки курса;
- ответ не сводится автоматически к `RETRAIN`;
- допустим аргументированный вывод «данных недостаточно».

# Датасет ЛР-13: Пространственные кластеры (DBSCAN)

## Контекст
Синтетический датасет для тестирования алгоритмов кластеризации, особенно плотностных (DBSCAN). Содержит кластеры различной формы и шум. Используется в лабораторной работе №13.

## Идентификаторы
- **point_id** – уникальный идентификатор точки (не признак).

## Признаки
- **x_coord** – координата по оси X (числовая).
- **y_coord** – координата по оси Y (числовая).

## Эталонная кластерная группа
- **reference_group** – категориальная метка, определяющая истинную принадлежность к кластеру или шуму. Возможные значения:
  - `moon_0` – точки первой «луны» (полумесяца).
  - `moon_1` – точки второй «луны».
  - `compact_blob` – компактное гауссово облако.
  - `noise` – шумовые точки (выбросы).

## Задача
Кластеризация. Особенно хорошо подходит для DBSCAN (кластеры произвольной формы, наличие шума). Метрики: silhouette score (если применимо), сравнение с эталоном (ARI, NMI).

## Примечания
- Данные уже нормализованы, дополнительная предобработка не требуется.
- Эталон используется только для валидации, не для обучения.

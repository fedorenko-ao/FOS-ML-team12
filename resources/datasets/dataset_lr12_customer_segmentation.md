# Датасет ЛР-12: Сегментация клиентов (K-means)

## Контекст
Набор данных для анализа покупательского поведения и выделения типовых групп потребителей на основе транзакционных метрик. Используется в лабораторной работе №12 для кластеризации методом K-means.

## Идентификаторы
- **customer_id** – уникальный идентификатор клиента (не признак).

## Признаки (все числовые)
- **annual_spend** – годовая сумма трат клиента (условные единицы).
- **visits_per_month** – среднее количество визитов (покупок) в месяц.
- **avg_basket** – средняя стоимость одной покупки (корзины).
- **online_share** – доля покупок через онлайн-каналы (0–1).
- **discount_share** – доля покупок со скидкой (0–1).
- **returns_rate** – доля возвращённых товаров (0–1).

## Целевая переменная (эталонный сегмент)
- **reference_segment** – категориальная метка, используемая для бенчмаркинга. Возможные значения:
  - `low_value` – низкая ценность (небольшие траты, редкие визиты).
  - `digital_loyal` – цифровой лояльный (высокая доля онлайн-покупок, регулярные визиты).
  - `premium` – премиум-клиенты (высокий средний чек и годовые траты).
  - `deal_seekers` – охотники за скидками (высокая доля покупок со скидкой, частые возвраты).
  - `atypical` – нетипичные клиенты (нестандартные комбинации признаков).

## Задача
Кластеризация (обучение без учителя). Метрики: silhouette score, индексы (Davies-Bouldin, Calinski-Harabasz), сравнение с эталоном (adjusted Rand index, NMI).

## Примечания
- Признаки имеют разный масштаб – требуется стандартизация.
- Эталонные метки используются только для финальной оценки, не для обучения.

# ЛР 17. Калибровка, пороги и устойчивость модели по подгруппам

## Цель

Показать, что одна итоговая метрика может скрывать важные изменения, а threshold является частью инженерной системы.

## Постановка

Студент получает вероятностные прогнозы бинарного классификатора, истинные метки контрольного периода, признаки для выделения подгрупп и описание стоимости FP/FN.

## Обязательные действия

1. Рассчитать precision, recall, F1, ROC-AUC, PR-AUC, confusion matrix.
2. Проверить calibration curve и Brier score либо аналогичный показатель.
3. Исследовать несколько threshold.
4. Построить таблицу стоимости ошибок при разных threshold.
5. Сравнить метрики минимум для двух подгрупп.
6. Найти ситуацию, где общая метрика приемлема, но одна подгруппа существенно хуже.
7. Предложить политику: единый threshold / обоснованно разный threshold / abstain-zone / human-in-the-loop.
8. Обосновать решение.

## Мини-задание 1

Найти threshold, который оптимизирует заданную стоимость ошибок, и показать его отличие от `0.5`.

## Мини-задание 2

Ответить на вопрос на основании notebook:

> Может ли модель с высокой общей ROC-AUC быть неприемлемой для эксплуатации?

## Критические ошибки

Работа требует доработки, если test используется для многократной оптимизации, threshold выбран формально, надёжность объявлена по одной метрике или студент не понимает различия результатов по подгруппам.

## Структура дисциплины

```markdown
Структура и содержание. Дисциплина включает базовые модули по данным, классическому обучению с учителем и обучению без учителя. В качестве предлагаемого усиления добавлен модуль 4 «Надёжность и жизненный цикл ML-систем», посвящённый эксплуатации модели после обучения: drift, мониторингу, калибровке, порогам решений, диагностике деградации и rollback/retraining. Конкретное распределение часов модуля 4 утверждается при обновлении РПД.
```

## Планируемые результаты

```markdown
* Диагностировать изменение данных и качества ML-модели после запуска, формулировать и проверять конкурирующие гипотезы причин деградации, обосновывать решение об эксплуатации, изменении порога, переобучении, откате или остановке модели и формировать план мониторинга.
```
